# Raw data

The raw dataset is not stored in this repository.

Source: Dubai Data / Dubai Pulse, "Metro Passengers Trips by Station Monthly"
(33,776 rows, 57 station labels; export dated 10 April 2026).

To reproduce notebook 01, download the CSV from the Dubai Data website and place it
in this folder. The cleaned data used by every later step is already in `data_processed/`.
